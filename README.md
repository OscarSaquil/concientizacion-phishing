# Concientización sobre Phishing — "¡Caíste!"

Sitio de aterrizaje para un **ejercicio de concientización sobre phishing** en entorno universitario.
Quien hace clic en el enlace del phishing *simulado* llega aquí: primero ve el meme del gatito
apuntando y riéndose con el mensaje "¡Caíste!", y luego la campaña educativa para aprender a
reconocer y reportar correos y enlaces maliciosos.

## Uso
- Finalidad **educativa y autorizada**. No captura ni almacena ningún dato de las personas.
- Sitio estático (`index.html`), publicado con GitHub Pages.

## Personalizar
- Cambia el correo de reporte en `index.html` (`soporte@tu-universidad.edu`).
- La ilustración del gatito está en `assets/`.
